# 个人主页

这是一个简洁现代的个人主页，展示个人信息、社交链接和项目作品。

## 特点

- 🎨 现代简约的设计风格
- 📱 完全响应式布局，支持移动端和桌面端
- 🖼️ 使用必应每日图片作为背景
- 🚀 轻量级实现，无需后端支持
- ⚡ 快速加载，性能优化

## 技术栈

- HTML5
- Tailwind CSS 3.0+
- Font Awesome 6.4.0
- 原生 JavaScript

## 功能特性

- 个人信息展示
- 社交链接集成
- 项目作品展示
- 动态背景图片
- 响应式设计

## 本地运行

1. 克隆仓库
```bash
git clone [你的仓库地址]
```

2. 使用浏览器打开 `index.html` 文件

## 自定义配置

### 修改个人信息
编辑 `index.html` 文件中的相关内容：
- 个人简介
- 社交链接
- 项目展示

### 更换图标
替换 `bitbug_favicon.ico` 文件即可更改网站图标

## 部署

可以直接部署到任何静态网站托管服务，如：
- GitHub Pages
- Netlify
- Vercel
- 传统虚拟主机
